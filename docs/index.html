Fonctionnalités

L'essentiel pour votre serveur, sans superflu.

Six modules pensés pour offrir une administration complète, fluide et sécurisée.

Modération & Automod

Sanctions graduelles avec escalade automatique paramétrable (warns, mute, kick, ban). Détection anti-spam, doublons et filtres regex en temps réel.

/warn Timeouts Anti-spam Regex

Logs & Audit Granulaire

Routeur de logs centralisé permettant de sélectionner précisément les événements du bot et du serveur à tracer dans vos salons dédiés.

Audit Discord Rôles & Salons Messages édités

XP & Niveaux Gamifiés

Système d'expérience paramétrable avec cooldown anti-spam, multiplicateurs d'XP par salon et attribution de rôles récompenses (cumul ou remplacement).

/niveau Leaderboard Multiplicateurs

Support & Système de Tickets

Panneaux interactifs avec boutons Discord pour ouvrir des canaux privés éphémères, et gestion des salons de support pour l'équipe staff.

Génération instantanée de salons vocaux temporaires dès qu'un membre se connecte au canal créateur, et suppression automatique dès que le salon est vide.

Déploiement

Installation en 4 étapes simples

Déployez Pyro sur votre serveur VPS, machine locale ou hébergement Pelican en quelques minutes.

1

Prérequis Système & Discord

Environnement Node.js v20+ requis. Créez une application sur le Discord Developer Portal et activez les Privileged Intents :

Node.js 20+ Server Members Message Content
2

Cloner & Compiler

Récupérez le code source, installez les dépendances et compilez le dashboard Svelte :

bash 
git clone https://github.com/SkillFXX/pyro-discord-bot.git
cd pyro-discord-bot
npm install
npm run build
3

Configuration (.env)

Copiez .env.example en .env et renseignez vos identifiants :

.env 
DISCORD_TOKEN=votre_bot_token
CLIENT_ID=votre_client_id
GUILD_ID=votre_guild_id
PORT=3000
SESSION_SECRET=cle_secrete_aleatoire
COOKIE_SECURE=false
NODE_ENV=production
4

Lancement du Bot

Démarrez Pyro. Le serveur Express et le bot s'initialisent conjointement :

bash 
npm start

Le dashboard est accessible sur http://localhost:3000. Connectez-vous avec votre DISCORD_TOKEN.

Commandes Slash

Commandes Discord disponibles

Commandes pré-enregistrées exploitant les interactions natives de Discord.

Commande Catégorie Description Permission
/niveau XP Affiche la carte de niveau et la progression d'un membre Tous
/topniveau XP Affiche le classement des membres les plus actifs Tous
/adminxp XP Ajoute, retire ou réinitialise l'XP d'un membre Administrateur
/warn Modération Avertit un utilisateur et enregistre la sanction Modérateur
/warns Modération Consulte ou réinitialise les avertissements d'un membre Modérateur
/mute Modération Exclusion temporaire (Timeout) avec durée personnalisée Modérateur
/kick Modération Expulse un utilisateur du serveur Modérateur
/ban Modération Bannit un utilisateur définitivement du serveur Modérateur
/sanctions Modération Affiche l'historique complet des sanctions d'un membre Modérateur
/ticketmod Support Gère les tickets (ajouter/retirer un membre ou ouvrir un ticket) Rôle Staff
